# Seek — 自作の汎用検索エンジン

ウェブ・画像・動画をまとめて検索できる検索エンジン。動画はページ内でそのまま再生できる。

## 機能
- **すべて**：ウェブ検索結果（次のページも読み込める）＋ Wikipedia の要約
- **画像**：画像をタイル状に表示し、クリックすると元のページを開く
- **動画**：サムネイル・長さ・再生数を表示し、クリックするとその場で再生

## 仕組み
1. ブラウザ（`index.html`）が、自作サーバーの `/api/search` に検索ワードを送る
2. サーバー（`server.py`、Python 標準ライブラリのみ）が、検索ワードに応じて結果を集める
   - ウェブ：DuckDuckGo の結果ページを読み取って、タイトル・URL・説明文を取り出す
   - 画像：Bing 画像検索の結果を読み取る
   - 動画：YouTube の検索結果ページに埋め込まれたデータ（JSON）を取り出す
   - 要約：Wikipedia の API を使う
3. 集めた結果を同じ形（JSON）にそろえてブラウザに返し、ブラウザ側で画面を組み立てる

## 動かし方
```
python server.py
```
起動したら http://localhost:8765 を開く。
